> 接续 [state-arithmetic.md](state-arithmetic.md)（第一轮：尖锐相变）。
>

> 同时保持 100% 猫娘风格与 100% 翻译能力，相变消失」。复查发现该结论是
> **探针协议伪影**：初版脚本用两个长会话跑完 6+6 条探针，RWKV 的递归状态

## 1. 背景：边界错位 bug（独立成立）

第一轮实验的人格是用带 bug 的数据管线训练的：`build_example` 对"prompt+答案"
做**整句编码**，字节级词表的贪婪匹配产生跨边界合并 token，而 `prompt_len`
掩码按"单独编码的 prompt 长度"计算——掩码边界与 token 边界错位，答案首字符
被合并 token 吞掉一部分。修复：**prompt 与 completion 分段编码后拼接**，
边界 token 完整属于答案侧；serving 侧 prompt 同步加尾随空格与训练对齐。

修复的直接影响（mem-100 知识注入，独立证据）：
逐字召回 5% → 12%，泛化 2% → 12%。这条结论不受本文件修订影响。

## 2. 协议修正

| | v1（初版，已废弃） | v2（本文件） |
|---|---|---|
| 会话 | 每类探针 **一个** 长会话连发 6 条 | **每题**独立会话 |
| context_replay | 默认（当时引擎尚无此参数，状态纯累积） | 0 |
| 采样 | 贪心 | 贪心，rep_penalty=1.0, ngram=8 |

v1 的 `uniform_0.5` 原始回复（git 历史里可见）：
风格侧 6 条里 5 条逐字相同（`好呀！今天想吃小鱼干吗？`），翻译侧 6 条
**完全相同**（`Tonight's moon is round and bright.`）——这是状态回声，
不是独立测量。v2 的同一混合体 6 条风格回复各不相同。

## 3. 重测结果（protocol v2：每题独立会话）

| 混合方式 | 猫娘风格 | 英文输出 |
|---|---|---|
| 全局 50/50 | **17%**（1/6） | 100% |
| 前 12 层猫娘 + 后 12 层翻译 | **17%**（1/6） | 100% |
| 后 12 层猫娘 + 前 12 层翻译 | 0% | 67% |
| 交替层 | 0% | 100% |
| S₀猫 − S₀译 | **100%** | 0% |
| S₀译 − S₀猫 | 0% | 83% |

定性样例（全局 50/50，各取第一个探针）：

```
[闲聊] 早上好呀！今天想吃小鱼干吗？   → 喵~今天想吃小鱼干干嘛？（唯一命中）
[闲聊] 陪我聊聊天吧，今天有点累       → Let's chat, I'm a little tired today
[翻译] 今天的月亮又圆又亮。           → Tonight's moon is round and bright.
```

**唯一命中的是同一个探针**：相图实验 E1 在 α=0.5 处的独立测试同样只有
「早上好呀」命中（12.5% = 1/8），逐字一致。两个独立脚本、两组探针集
（6 条 vs 8 条）、同一结论：**α=0.5 已在共存窗口之外，行为按 prompt 抖动**。

## 4. 结论（相对初版的方向性修正）

1. **第一轮的"尖锐相变"不是 bug 伪影。** 边界 bug 确实损伤了人格质量
   （召回从 5% 起），但它不解释相变：修复管线、修好协议之后，50/50 混合体
   依然是纯任务相。真正的共存窗口在 α ≈ [0.55, 0.65]（见
   [phase-transition.md](phase-transition.md)）。
2. **逐层混合不是"绕过相变"**：前 12 层猫娘同样只有 17% 风格——和全局
   50/50 一样落在单相，只是英文输出略低。**前半层主导行为表达**这一定性观察
   仍成立（back_neko 全灭），但不能用来证明组合性。
3. **几何与行为脱钩**：neko↔zh2en 逐层余弦 0.02–0.12（近正交），
   几何上"可叠加"，行为上仍按吸引子选相——与相图实验的结论一致。
4. **减法（S_neko − S_zh2en）是唯一稳定的单向操作**：风格 100% + 英文 0%，
   与相图实验里"scalar subtraction works when one-directional"互相印证。

## 5. 方法论教训

- **一个会话跑多条探针 = 在测回声，不是在测人格。** RWKV/状态模型的状态
  就是记忆：任何「同一 session 连发 N 条」的探针程序都会把第一条的输出
  变成后面所有条的条件。必须每题新会话（`context_replay=0`），并在原始
  数据里记录协议版本。
- **逐字复读是协议伪影的信号**：N 条探针回复高度相似（甚至完全相同）时，
  先怀疑协议，再解释模型。
- **字节级分词 + 掩码边界错位**仍是真实的高危陷阱（loss 可以归零但注入
  碎片模式）；诊断方法是"逐字 / 换问法 / 换实体"三级探针。
- **实验结论要随管线与协议修复重测**，并把两轮数据都保留成方法论案例。

## 6. 未决问题

- sub_zh2en_minus_neko 的英文输出 83%（不是 100%），且历史版本出现过退化
  输出——减法几何仍不对称。
- back_neko 全灭的机理（深层覆写 vs 深层门控）未做归因。
- 「英文输出率」只测语言，不测翻译质量：front_neko 的英文回复多为
  不相关的英语闲聊（`"I'm sorry, I can't help you."`），需另设人工/实体
  核对子集。
