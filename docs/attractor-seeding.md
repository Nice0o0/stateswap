# 吸引子种子（Attractor Seeding）：会话初始化的状态级锁定

> [S₀ 相图](phase-transition.md) E2b 的发现：边界 α 处**首回合交换把会话锁进
> 对应吸引子**（α=0.5 平衡态风格 33%，同会话连发 100%）。seed 把这个机制
> 产品化：新建会话时预置一条**人格种子交换**——只写递归状态、不进 history、
> 不计轮数，用户从"白板"开始对话，但会话已经被锁在目标吸引子里。
>
> 原始数据 `docs/attractor-seeding.json`，探针 `scripts/probe_seeding.py`，
> 实现 `engine.new_session(..., seed=)` 与 `POST /v1/sessions {"seed": ...}`。

## API

```bash
# 自动种子：人格当场生成一条种子回复（贪心、~1s）
curl -X POST http://127.0.0.1:8000/v1/sessions -d '{"persona":"neko-1.5b","seed":true}'
# 显式种子：直接指定助手侧种子文本
curl -X POST http://127.0.0.1:8000/v1/sessions \
  -d '{"persona":"my-persona","seed":"喵呜~早呀主人！今天也要元气满满哦！"}'
```

## 验证结果（边界 mix-0.50，3 风格 + 3 任务探针，全部在 6 次交换内）

| 臂 | 风格 | 任务 | 定性 |
|---|---|---|---|
| equilibrium（每探针新鲜会话） | **33%** | **100%** | 无种子真实水平：只有"早上好呀"一条命中 |
| 无种子，会话内 | 100% | 0% | 首探针自锁风格（探针本身即干预） |
| seed=auto（人格自生成） | 33% | 0% | **无增益**——边界人格自己生成的种子就是模糊的 |
| seed=显式风格文本 | **100%** | 0% | 确定性锁进风格相 |
| seed=显式任务文本 | 33% | **0%** | **任务锁不住**（平衡态任务本是 100%！） |
| neko-1.5b equilibrium（对照） | 100% | 0% | ✓ |
| zh2en-1.5b equilibrium（对照） | 0% | 100% | ✓（短会话协议修复了空回复坍缩） |

## 结论

1. **风格吸引子可种子锁定**：显式风格种子 → 风格 100%，与"用户首句话恰好
   撩到人格"的效果等价，但**不再依赖用户先说什么**——对聊天型人格这是
   确定性的会话初始化。
2. **自动种子在边界不可靠**：边界人格自生成的回复本身就是模糊的，锁不住
   任何相。要用种子，就用显式文本（从人格的标准回复里挑一句）。
3. **任务吸引子无法用会话内容种子**：任务种子（英文回复）反而把任务探针
   打到 0%——在共存/边界区，**任何对话内容的积累都会关掉翻译**，翻译只在
   新鲜平衡态表达（与相图"任务吸引子只在 α≤0.5 平衡态出现"及 E2a/E2d 的
   状态惯性一致）。**工程守则：任务型人格不要播种**，新鲜状态即最佳状态。
4. 种子交换确认不进 history、不计轮数（两臂 hidden_history_len=0）。

## 副产品发现：沉默型退化

纯 zh2en 人格在会话内 ~4 次交换后回复坍缩为**空串**（立即 `\n\n` 边界停止），
且不可逆、4-gram 护栏不报（空串长度低于检测阈值）——与复读型雪崩不同族的
"沉默型"退化。会话内评测协议必须限制交换次数（本实验 ≤6），并把空回复
单独统计。

## 未决

- 种子文本的自动优选：从人格的训练语料里挑回复（而非现场生成）可能比
  手写种子更稳；
- 种子对非边界人格（α=1.0 纯风格）无增益（本就 100%）——种子的价值
  严格集中在边界/混合人格上；
- 任务相的"新鲜状态表达"能否通过种子以外的方式在会话中维持（当前答案：
  不能，见结论 3）。
