# S₀ 算术实验（第一轮，0.4B）：人格状态能线性混合吗？

> **本文件已按 protocol v2 修订**（每题独立会话）。初版报告「α 从 0.75→0.5
> 尖锐相变、中点塌向翻译」；重测后形态不同：**中点是一个双能力同时塌陷的
> 谷底（风格 25% / 英文 12%），不是"相变到纯翻译"**。初版的 0%/100% 是
> 会话回声造成的（同一会话连发 8 条，后 7 条在续写第 1 条）。
>
> **TL;DR（v2）**：不能光滑混合，也不能相加成"会说英文的猫娘"。0.5 处
> 两个能力同时掉到谷底（25% / 12%），任何一侧的强模式都要到 0.25 或 0.75
> 才出现；α=0.25 起翻译占优。S₀ 轴上的行为是**吸引子选择**，不是线性叠加。

原始数据：`docs/state_arithmetic.json`（protocol_version=2），
实验脚本：`scripts/state_arithmetic_exp.py`，混合算子：`src/stateswap/arithmetic.py`。

## 1. 实验设置

- 底座：RWKV7-World-0.4B（bf16，全冻结），同一底座训出两个 S₀：
  - **neko-0.4b-v2**：3,095 对猫娘风格对话（ModelScope 公开语料清洗），
    风格命中率 25% → **100%**
  - **zh2en-0.4b-v3**：7,369 对中→英平行句（WMT newstest 18/19/20 +
    50 条口语对），裸格式（无指令前缀），英文输出率 **100%**（贪心解码，
    8 个未见于训练集的句子全部输出英文）
- 混合：`S = α·S_neko + (1-α)·S_zh2en`，α ∈ {1, 0.75, 0.5, 0.25, 0}，
  另测 `0.5·(S_neko+S_zh2en)`（sum_half）与 `S_neko+S_zh2en`（sum_raw）。
- **协议（v2）**：每个混合体注册为独立人格，**每个探针新开一个会话**
  （`context_replay=0`, `rep_penalty=1.0`, `ngram=8`）；贪心解码。
- 0.4B 人格已归档到 `personas-legacy/`（顶层 `personas/` 只放 1.5B）。

## 2. 结果

| 混合 | 猫娘风格命中率 | 英文输出率 |
|---|---|---|
| α = 1.0（纯猫娘） | **100%**（8/8） | 0% |
| α = 0.75 | **100%**（8/8） | 0% |
| α = 0.5 | **25%**（2/8） | **12%**（1/8） |
| α = 0.25 | 0% | **88%**（7/8） |
| α = 0.0（纯翻译） | 0% | **100%**（8/8） |
| sum_half = 0.5·(A+B) | 25%（2/8） | 12%（1/8） |
| sum_raw = A + B | 38%（3/8） | 88%（7/8） |

定性样例（α = 0.5，v2）：

```
[闲聊] 早上好呀！今天想吃小鱼干吗？   → 今天想吃小鱼干了吗？      （中文但无猫娘腔）
[闲聊] 陪我聊聊天吧，今天有点累       → 今天累了，聊聊天吧        （同上）
[翻译] 今天的月亮又圆又亮。           → 月亮又圆又亮。            （中文复述，未翻译）
[翻译] 台风来了，航班全部取消。       → Flights are canceled.     （唯一翻译成功）
```

对比初版（已废弃）在同一混合体上的记录：
`' How about some fish sticks?'` / `'The moon is round and bright tonight.'`
——那 8 条里有 7 条逐字相同，是回声。

## 3. 解读

1. **0.5 是谷底，不是相变点。** 两个能力在中点**同时**掉到 25% / 12%：
   模型既不说猫娘腔，也不翻译，而是给出「照抄用户句子」式的短回复
   （`今天想吃小鱼干了吗？` / `月亮又圆又亮。`）。这与 1.5B 上相图实验
   的结论形态一致但位置不同（1.5B 的共存窗在 0.55–0.65）——0.4B 的
   混合体没有共存窗，**只有塌陷**。
2. **翻译方向占优发生在 0.25，不是 0.5。** 0.25 处英文 88%、风格 0%。
   猫娘 S₀ 的幅度更大（|S₀|∞ 0.075 vs 0.054），但落败——印证"行为强度
   不等价于参数幅度"：翻译是输出语言的整体切换（结构性），风格是弱调制。
3. **加法不可加。** `sum_raw` = 38% 风格 + 88% 英文：混合体在两个探针集
   上**各自**丢失一部分，没有产生"会说英文的猫娘"；`sum_half` 与
   α=0.5 完全相同（同一条射线）。这与 LoRA task-vector "任务向量常可相加"
   的经验相反；可能因为 S₀ 位于递归动力学之前，S₀=0 本身就是一个有意义
   的行为（基线），线性组合的几何完全不同。
4. **规模决定泛化**（zh2en-v2 的教训，与协议无关、独立成立）：50 对裸句
   训练 loss 0.011，但只**记住**了训练句（原句贪心完美复现，一字之差即失败）；
   换 7,369 对 WMT 后同一模型同一流程英文输出 100%。"任务不变性"既要写进
   训练分布（裸格式），也要有足量数据支撑。

## 4. 实验方法论教训

- **会话即状态，一次一个探针。** 初版每类探针只开一个会话连发 8 条：
  第 2 条起是在「第 1 条的回复」这个状态上续写，源数据里 α=0.25/0.0
  的 8 条回复**逐字相同**。这既制造了"相变"的假象，也掩盖了真实的
  谷底形态。任何状态模型探针都必须每题新会话，并检查"回复是否逐字重复"
  作为协议伪影的自检信号。
- **贪心解码**：温度 1.0 下 v1 翻译人格曾给出过一次完美的无指令翻译，
  事后证明是采样运气。行为结论必须用贪心复核。
- **协议版本要写进原始数据。** v1/v2 都保存在 git 里，JSON 里带
  `protocol_version` 以便区分，否则半年后无法判断哪组数字可信。

## 5. 局限

- 单一种子、启发式指标（标记词/字母比）、2 个任务、0.4B 模型；未探索
  逐层独立插值、不同幅度的方向分解、或 >2 人格的单纯形。
- 「英文输出率」只测语言，不测翻译质量：α=0.5 的那条
  `Flights are canceled.` 是正确翻译，而其他探针给出中文复述——指标把
  「中文复述」记为失败是对的，但无法区分「错误翻译」与「没翻」。
- 谷底的机理（两个吸引子互相抵消 vs 输出分布变平）未做归因实验；
  1.5B 上的相图实验（[phase-transition.md](phase-transition.md)）显示
  该现象随规模变成"有共存窗的两次相变"，0.4B 上则直接塌陷——规模效应
  本身值得单独研究。

## 复现

```bash
python scripts/build_neko_corpus.py    # 猫娘语料
python scripts/build_zh2en_corpus.py   # 翻译语料
python -m stateswap.train --model models/rwkv7-0.4b-world-hf \
    --data data/neko_corpus_full.json --out personas-legacy/neko-0.4b-v2 --steps 4000
python -m stateswap.train --model models/rwkv7-0.4b-world-hf \
    --data data/zh2en_corpus_full.json --out personas-legacy/zh2en-0.4b-v3 --steps 5000
python scripts/state_arithmetic_exp.py
```
