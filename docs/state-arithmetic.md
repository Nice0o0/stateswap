# S₀ 算术实验：人格状态能线性混合吗？

**TL;DR：不能光滑混合。两个任务人格的 S₀ 在插值轴上呈尖锐相变，中点不是
"半猫娘半翻译"，而是整体塌向更强的那个任务模式；直接相加同样只会留下
单一行为。与 LoRA task-vector 常见"可加"的直觉相反。**

原始数据：`docs/state_arithmetic.json`，实验脚本：`scripts/state_arithmetic_exp.py`，
混合算子：`src/stateswap/arithmetic.py`。

## 1. 实验设置

- 底座：RWKV7-World-0.4B（bf16，全冻结），同一底座训出两个 S₀：
  - **neko-0.4b-v2**：3,095 对猫娘风格对话（ModelScope 公开语料清洗），
    风格命中率 25% → **100%**
  - **zh2en-0.4b-v3**：7,369 对中→英平行句（WMT newstest 18/19/20 +
    50 条口语对），裸格式（无指令前缀），翻译成功率 **100%**（贪心解码，
    8 个未见于训练集的句子全部输出英文）
- 混合：`S = α·S_neko + (1-α)·S_zh2en`，α ∈ {1, 0.75, 0.5, 0.25, 0}，
  另测 `0.5·(S_neko+S_zh2en)`（sum_half）与 `S_neko+S_zh2en`（sum_raw）。
- 每个混合体注册为独立人格，各开 **两个独立会话** 分别测风格与翻译
  （会话状态包含对话历史，混用会互相污染——见 §4）。
- 解码：贪心（温度 0），排除采样运气。

## 2. 结果

| 混合 | 猫娘风格命中率 | 翻译成功率 |
|---|---|---|
| α = 1.0（纯猫娘） | **100%** | 0% |
| α = 0.75 | 100% | 0% |
| α = 0.5 | 0% | **100%** |
| α = 0.25 | 0% | 100% |
| α = 0.0（纯翻译） | 0% | 100% |
| sum_half = 0.5·(A+B) | 0% | 100% |
| sum_raw = A + B | 12% | 100% |

定性样例（α = 0.5）：

```
[闲聊 prompt] 早上好呀！今天想吃小鱼干吗？
[回答] ' How about some fish sticks today?'   ← 模型把闲聊也翻译成了英文

[翻译 prompt] 今天的月亮又圆又亮。
[回答] 'The moon is round and bright tonight.'
```

## 3. 解读

1. **尖锐相变，而非线性混合**：α 从 0.75 → 0.5，行为从"纯猫娘"直接跳到
   "纯翻译器"，中点处猫娘风格完全消失（0/8）。S₀ 空间中两个任务模式
   更像两个吸引子，插值中途模型被"拽"进主导模式，而不是两者叠加。
2. **翻译方向赢了**：尽管猫娘 S₀ 的幅度更大（|S₀|∞ 0.075 vs 0.054），
   中点及加法混合后都是翻译模式胜出。任务模式的"行为强度"不等价于
   参数幅度——翻译是强结构性任务（输出语言整体切换），风格是弱调制。
3. **加法不可加**：sum_raw 与 sum_half 都不产生"会说英文的猫娘"，
   而是 100% 翻译 + 残余风格痕迹。这与 LoRA task-vector 合并文献中
   "任务向量常可相加"的经验相反，可能源于：S₀ 位于与输出隔了整个
   递归动力学的初始状态空间，两个 S₀ 的"行为方向"不经过原点
   （S₀=0 已是一个有意义的行为：基线模型），线性组合的几何完全不同。
4. **规模决定泛化**（zh2en-v2 的教训）：50 对裸句训练 loss 0.011，
   但只**记住**了训练句（原句贪心完美复现，一字之差即失败）；
   换 7,369 对 WMT 后同一模型同一流程泛化到 100%。
   "任务不变性"既要写进训练分布（裸格式），也要有足量数据支撑。

## 4. 实验方法论教训（同样适用于 state tuning 类工作）

- **会话即状态**：风格与翻译探测必须用独立会话。第一版实验两者共用
  一个会话，8 轮猫娘对话的历史写进了递归状态，翻译探测全部变成
  "继续聊天"——0% 是会话污染的假象，不是模型能力。RWKV 的状态就是
  上下文，任何评测都必须显式管理它。
- **贪心解码**：温度 1.0 下 v1 翻译人格曾给出过一次完美的无指令翻译，
  事后证明是采样运气。行为结论必须用贪心复核。

## 5. 局限

- 单一种子、启发式指标、2 个任务、0.4B 模型；未探索逐层独立插值
  （layer-wise mixing）、不同幅度的方向分解、或 >2 人格的单纯形。
- "相变"的机理（吸引子竞争 / 输出分布的 mode switching）未做归因实验。

## 复现

```bash
python scripts/build_neko_corpus.py    # 猫娘语料
python scripts/build_zh2en_corpus.py   # 翻译语料
python -m stateswap.train --model models/rwkv7-0.4b-world-hf \
    --data data/neko_corpus_full.json --out personas/neko-0.4b-v2 --steps 4000
python -m stateswap.train --model models/rwkv7-0.4b-world-hf \
    --data data/zh2en_corpus_full.json --out personas/zh2en-0.4b-v3 --steps 5000
python scripts/state_arithmetic_exp.py
```
