# S₀ 外科实验：低秩定向编辑能做什么、不能做什么

> 研究问题：对人格 S₀ 施加 rank-k 低秩定向扰动，能否**精准切除一个行为而保留
> 另一个**？这是[人格解剖](persona-anatomy.md)（行为住在低维子空间）与
> [S₀ 相图](phase-transition.md)（行为由吸引子选择）两个观察性结论的**干预性验证**：
> 如果低秩切除可行，"人格在低维子空间"就从解释升级为工具；如果不可行，
> 损伤曲线就是吸引子纠缠度的直接测量。
>
> 原始数据 `docs/state-editing.json`，算子 `src/stateswap/editing.py`，
> 脚本 `scripts/probe_editing.py`。协议与相图实验一致（贪心、独立会话、
> context_replay=0、8 风格 + 8 任务探针）。
>
> related work：ROME-on-Mamba（2404.03646）编辑的是**权重**；DREAMSTATE
> （2601.19221）用扩散**生成**状态；State Soup 混合技能状态。本文编辑的是
> **训练出的人格 S₀ 本体**，机制与目标均不同。

## TL;DR

1. **切除不是外科，是格式化**：从共存相混合体（mix-0.60：风格 87.5% + 任务 75%）
   切除任一端人格的 top-k 奇异子空间（k=1..16 任意档），**两个能力同时塌陷**，
   行为回归 **S₀=0 基线**（素中文闲聊，无标记、无翻译）。切除没"留下另一个
   行为"，而是删掉了整个训练态信号。
2. **注入与缩放是有效的"相图导航"**：沿风格方向注入（+λ·rank4(neko)，几何上
   cos 0.99 的微扰）→ 立即滑入纯风格相（风格 100%，任务 0）；向任务方向缩放
   （M − 0.3·neko）→ 任务相（任务 100%，风格 12%）。**编辑 = 相图上的可控
   移动，但不能停在共存相**——18 个编辑产物无一保持双能力。
3. **几何-行为脱钩第三次确认**：注入 λ=0.2（Frobenius 距离 1.79，逐层余弦
   0.99）就造成行为完全翻转（任务 75%→0）。相变边界对状态幅度的敏感度远超
   几何直觉。

## 实验设置

- 对象：mix-0.60（neko-1.5b × zh2en-1.5b 共存相混合体，见 phase-transition.md）。
- 算子（`src/stateswap/editing.py`）：
  - **切除** `remove_subspace(s, ref, k)`：S' = (I − U Uᵀ) S (I − V Vᵀ)，
    U/V 为 ref 逐头 SVD 的前 k 奇异向量——移除 s 中活在 ref 奇异行/列空间里的分量；
  - **注入** `inject(s, direction, λ, k)`：S' = s + λ·rank-k(direction)；
  - **基线**：标量算术（`arithmetic.subtract` 与整体缩放）。
- rank 档位 k ∈ {1, 2, 3, 4, 8, 16}；每个配置 8 风格 + 8 任务探针；退化护栏
  标记全程记录（18 个配置（17 编辑 + 基线）共 288 次生成，**零退化**——编辑产物都在相干流形上）。

## 结果总表

| 配置 | 风格 | 任务 | ‖Δ‖_F | 行为定性（探针原文见 json） |
|---|---|---|---|---|
| base mix-0.60 | 87.5% | 75% | 0 | 共存：闲聊猫娘化，陈述句素中文 |
| e1 切风格 k=1 | 12.5% | 25% | 4.28 | **素中文基线**（"好呀！我想吃小鱼干！"） |
| e1 切风格 k=2..16 | 12.5% | 0% | 5.23–7.30 | 同上，k 增大行为不再变化 |
| e2 切任务 k=1..16 | 12.5% | 0–25% | 3.68–6.71 | 同上（任务探针输出"这句话的意思是…"解释腔） |
| e3 M − 0.3·neko | 12.5% | **100%** | 3.42 | 任务相 |

| e4 +0.2·rank4(neko) | **100%** | 0% | 1.79 | 风格相（几何微扰、行为全翻） |
| e4 +0.4·rank4(neko) | 100% | 0% | 3.58 | 风格相 |

## 三个结论

### 1. 切除 = 格式化回基线，不是"留下另一个行为"

E1/E2 的所有档位行为一致：**素中文**（无标记、未翻译、无结构）。机制：混合体的
两个行为由两个训练吸引子支撑，切除任一端的 top-k 子空间后，状态不再与任何
训练吸引子对齐 → 递归动力学回落到底座 S₀=0 的行为。切除移除的是"训练态
信号"本身，不是信号中的一个成分。注意 style 12.5% 是**指标伪影**：基线闲聊
"我想吃小鱼干"的内容词命中了标记词表（"小鱼干"）——启发式指标的已知边界。

E1 与 E2 完全同构（对称塌陷）也与切除的数学一致：近正交的两端，切谁都是
"删掉一半训练信号"。

### 2. 编辑 = 相图导航（这是有效的部分）

注入与缩放类编辑把系统**可预测地**推入目标相：沿风格方向加 → 风格相；
向任务方向减 → 任务相。编辑产物行为与相图上对应 α 位置的平衡行为一致
（e3-scale-0.3 ≈ mix-0.5 的行为）。**编辑算子可以充当"相图上的方向盘"，
但共存相是测度零的刀锋，任何扰动都会滑出**——它不是"两种行为的可分离
叠加"，而是两个吸引子在精确配比下的不稳定平衡。

### 3. 工程含义：人格编辑的可行操作集

| 想做什么 | 可行算子 | 不可行算子 |
|---|---|---|
| 把共存人格推向某个相 | inject / 标量缩放 | — |
| 从混合体得到单一行为人格 | 标量减法（e3）| 子空间切除（回基线）|
| 只删一个行为保留另一个 | **无（本轮阴性）** | remove_subspace |
| 微调人格强度 | 小 λ 注入（cos 0.99 量级即可生效）| — |

## 方法论教训

- **切除的"rank-1"在几何上并不小**：人格 S₀ 的 top-1 奇异方向携带大量范数，
  切除后 Frobenius 距离 4.28——"低秩=微扰"的直觉对**注入**成立（cos 0.99），
  对**切除**不成立。
- 内容词 marker 伪影再现（"小鱼干"是标记词也是普通名词）——启发式指标的
  边界要写进每份报告。
- 算子单测必须覆盖**重构等价性**（rank-64 截断 = 原矩阵）：实现时奇异值
  广播错轴（`sv[:, :k, None]` 乘到行轴）在 k=64 时形状合法、数值全错，
  k<64 才暴露——正是全秩等价测试抓住了它。

## 未决问题

- **分层切除**：本轮对所有 24 层均匀切除。解剖与 E3 地形显示能力有层地址
  （任务前层 / 风格 L16–19）——只在特定层区间切除 ref 子空间，能否避开
  "格式化回基线"、实现真外科？这是本实验最自然的续篇。
- **软切除**：(I − βP)（β<1 部分缩放）能否在基线回归与完整保留之间找到
  保留双能力的中间带？
- 第三人格方向的注入（真正意义的"加新行为"）需要第三个训练吸引子作为
  方向源——与人格炼丹厂联动。
